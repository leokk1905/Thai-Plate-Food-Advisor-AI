Leave this blank and the itinerary picks randomly from whatever passes your filters above. Fill it in and the pipeline becomes RAG: the dishes that pass your filters get re-ranked by embedding similarity to what you typed (the retrieval step), and the LLM is given that ranked, scored list to write from (the generation step) -- see "Retrieved candidates" below the result once you run it.

Known limitations -- read before drawing conclusions from this page

  • Small sample dataset. This runs on a demo set of a few dozen dishes, not a real production database. Results are illustrative of how the system behaves, not a real guide to Thai cuisine.
  • Allergen/diet tags are only as complete as the ingredient lookup table. They come from a hand-built mapping of ingredient names to allergen categories. Some ingredients (generic terms like "spices" or "vegetables" from one of the data sources) aren't in that table yet -- those dishes are not confirmed allergen-free, they're simply untagged. Do not use this for a real allergy decision.
  • Spice level and flavor profile are AI-generated estimates, not verified facts -- they come from a language model's best guess, not a reference source.
  • Embedding similarity (used by the free-text search above, and by the itinerary's optional "what are you craving" field) is unreliable for hard constraints. It's good at matching taste and style ("sour and spicy"), but testing has shown it can rank a dish wrong for strict categories like "vegetarian" or a specific region. That's exactly why the itinerary generator always runs the deterministic allergen/diet/region/spice filter first and only lets embedding similarity re-rank within that already-safe set -- it never lets similarity scores override a safety constraint. The plain search box above has no such filter, so don't treat its results as allergen-safe.
  • Narrow filters can repeat the same dish across days. If very few dishes match (e.g. a strict diet combined with one region), the itinerary may show the same dish more than once instead of warning you about limited variety.
  • This is a local prototype. It isn't deployed publicly, has no accounts, and nothing you enter here is saved anywhere.
